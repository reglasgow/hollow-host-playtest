# HOLLOW HOST: Android playtest

A top-down horror roguelite where you play a parasite inside a dead colossus. Move with the left thumb and aim/shoot with the right. Explore rooms, collect relics and fight towards the heart.

**Early test build, not a finished release.** The game currently has Italian text and tutorial. Development uses AI tools, including code assistance and generated artwork. Contains stylized blood and body-horror imagery.

## First-impression test

Participation is free, voluntary and unpaid. Try the tutorial and a few rooms for about 10–15 minutes; that is a requested test window, not a measured run duration. You do not need to finish a run.

1. When did the movement or aiming controls first feel confusing?
2. Could you tell an open exit, a closed exit and a continuous wall apart?
3. Where did you stop, and what made you stop?

Leave feedback under the Reddit post where you found the game. Short, critical feedback is useful. Phone model and Android version are optional. Do not post email addresses or other personal details. A game-only clip is optional; no camera or microphone is requested. No ratings, purchases or reciprocal-testing promises.
