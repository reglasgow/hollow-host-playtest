# HOLLOW HOST: Android playtest

A top-down horror roguelite where you play a parasite inside a dead colossus. Move with the left thumb and aim/shoot with the right. Explore rooms, collect relics and fight towards the heart.

**Early, free, voluntary and unpaid playtest.** Italian and English are available; choose in Settings > Language. Development uses AI tools, including code assistance and generated artwork. Contains stylized blood and body horror.

## A useful first test

Try the tutorial and a few rooms for10–15minutes. This is a requested test window, not a measured average run duration. You do not need to finish a run.

1. When did movement or aiming feel confusing?
2. Could you distinguish an open exit, a closed exit and a continuous wall?
3. Where did you stop, and what made you stop?

Use **FEEDBACK** in Settings, Pause or after a run. Up to1500characters; please do not include personal details. Device model and Android version are optional if you choose to mention them. Feedback is sent only when you press SEND, and works even if you decline the other measurements. No purchases, ratings or reciprocal-testing promises.

## Optional measurements and privacy

**Analytics are disabled until you explicitly enable them.** You can decline and play normally. With consent,0.6.15 sends active play time, movement/aim time, tutorial progress, room visits, run outcomes, semantic button actions and coarse12×8initial control-touch cells to the existing PostHog Cloud USA project. It uses a random code, not a name, email or advertising ID. No screen/audio/keyboard recording, session replay or analytics SDK is included. Only the Android INTERNET permission is requested.

Written feedback is a separate deliberate submission and includes game version and session/room context. Offline submissions are queued locally with bounded retries when the game runs again. Stop analytics or request data deletion from Settings > Playtest analytics. A deletion request is handled by the team; it is not an immediate automated purge. The free project's one-year query window does not guarantee automatic deletion. The previous0.6.14 release remains available as an offline build without measurements.

Automated native checks, actual synthetic ingestion, stored event UUIDs, signed package and exact compiled APK resources were verified. Internal tests are excluded from the player dashboard. **Physical Android/emulator validation, human balance, audio listening and battery measurements are NOT RUN by the agent.** Current in-game music remains unchanged while new soundtrack/trailer proposals await the founder's choice. No Reddit recruitment announcement has been published yet.

Source stays in a separate private repository; this public repository contains only test binaries and instructions.
