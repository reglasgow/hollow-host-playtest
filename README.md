# SUTURE WAKE — Android playtest

Formerly **HOLLOW HOST**. A native mobile horror roguelite by Game CREEP.

[Join the Google Play test](https://reglasgow.github.io/suture-wake-playtest/test/) · [Android candidates](https://github.com/reglasgow/suture-wake-playtest/releases) · [Privacy](https://reglasgow.github.io/suture-wake-playtest/privacy.html)

The Google Play test may still display the previous name while its next store update is prepared. A founder APK candidate is separate from the Play application; its saves do not transfer automatically.

Game source stays in the private repository. This public repository contains distribution material only. Original release filenames and evidence are retained for provenance. Analytics require voluntary in-game consent. Development and art are AI-assisted.
